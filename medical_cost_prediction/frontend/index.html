How the estimate is built

01

Your six inputs

Age, sex, BMI, number of children, smoking status and region are the features the model uses. Nothing else is collected.

02

Polynomial expansion

The inputs are scaled, one-hot encoded, then expanded into degree-2 terms so the model can capture curves and interactions.

03

Linear regression

A least-squares fit over those terms returns one predicted annual charge, which this page displays in USD.
